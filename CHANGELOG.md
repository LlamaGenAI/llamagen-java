# Changelog

All notable changes to `llamagen-java` are documented in this file.

## 0.1.0 - 2026-07-08

### Added

- Initial Java SDK for LlamaGen Comic API and Animation API.
- `LlamaGenClient` with `comic()` and `animation()` resource namespaces.
- Typed params and response models for comic generation, continuation, panel regeneration, reference uploads, usage, and video artwork generation.
- Per-request `RequestOptions`, retry handling, webhook signature verification, Maven and Gradle build files, and CI.
