# Security Policy

## Supported Versions

Security fixes are provided for the latest released minor version of `llamagen-java`.

## Reporting a Vulnerability

Please do not open a public issue for a vulnerability.

Email `support@llamagen.ai` with:

- Affected version.
- Description of the issue.
- Steps to reproduce or proof of concept.
- Any known mitigation.

We will acknowledge reports as soon as possible and coordinate a fix before public disclosure.

## Secrets

Never commit API keys, webhook secrets, npm tokens, Maven credentials, or GitHub tokens. Use environment variables or secret managers.
