# Code of Conduct

We want this project to be useful, kind, and practical for developers building with LlamaGen.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent when reviewing issues and pull requests.
- Keep feedback focused on the code, docs, API behavior, and developer experience.
- Help maintain a welcoming space for people with different backgrounds and skill levels.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Personal attacks or sustained disruption.
- Publishing private information without permission.
- Spam or intentionally misleading contributions.

## Reporting

Report concerns to `support@llamagen.ai`. Maintainers will review reports and take action that fits the situation, including warnings, moderation, or removal from project spaces.
